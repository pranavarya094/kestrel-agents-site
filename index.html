    What a first pilot could look like.

    A realistic scenario, so you can see how scope, review and measurement are set out before we start anything.

    Weekly lead list for a small B2B software companyExample scenario
    The task
    Every Monday, a list of 20 companies that match the ideal customer, each with a named contact and a one-line reason to reach out.
    Agents involved
    A lead scout finds companies, a researcher reads each website, a writer drafts the first message, and a checker verifies contact details and claims.
    What you review
    The list and the drafts, before anything is sent. You approve, edit or reject each one.
    How we measure it
    Hours saved per week, the share of leads you would actually contact, and replies to the messages you chose to send. Targets are agreed in writing before we start.
    How it starts
    Scope is agreed on the discovery call, followed by a short build and test period using your real examples.

    How a project runs.

    Small start, clear results, then more agents once the first one has proven itself.

    1. Discovery call

      30 minutes, free. We look at your week and pick one repeatable task that costs you hours.

    2. Pilot scope

      We write down what the agent will do, which tools it can use, what a good result looks like, and who approves. Scope and price are agreed in writing before work starts.

    3. Build and test

      We build the agent with your tools and test it on real examples from your business.

    4. Run and review

      You read the logs and approve outputs. We tune the agent until you trust it with that task.

    5. Add teammates

      Once one agent works, we add the next: researcher, writer, checker, outreach.
